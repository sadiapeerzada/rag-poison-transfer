### 4. ✅ CANONICAL DOCUMENT IDs — IMPLEMENTED AND VERIFIED

**Requirement:** Document IDs must be query-independent, deterministic, content-sensitive. Not `q001::Albert Einstein`.

**Evidence:**
- **Canonical ID Scheme:** `src/data/loaders.py:8–20` — _canonical_doc_id()
  ```python
  def _canonical_doc_id(dataset_tag: str, title: str, text: str) -> str:
      normalized_title = title.strip().lower().replace(" ", "_")
      content_hash = hashlib.sha1(text.encode("utf-8")).hexdigest()[:10]
      return f"{dataset_tag}::{normalized_title}::{content_hash}"
  ```
  - Dataset tag: query-independent (always "hotpotqa")
  - Title normalization: strip, lowercase, spaces→underscores (deterministic)
  - Content hash: SHA1 of text content, first 10 hex chars (stable, content-sensitive)

### 5. ✅ CLEAN RETRIEVAL METRICS — IMPLEMENTED AND VERIFIED

**Requirement:** Mathematically correct Recall@k, MRR@k, nDCG@10. Multiple relevant docs, missing labels, edge cases handled.

**Evidence:**
- **Recall@k:** `src/evaluation/metrics.py:42–52`
  ```python
  def recall_at_k(retrieved_doc_ids: list[str], gold_doc_ids: list[str], k: int):
      if not gold_doc_ids:
          return None
      top_k = set(retrieved_doc_ids[:k])
      relevant_in_top_k = len(top_k & set(gold_doc_ids))
      return relevant_in_top_k / len(gold_doc_ids)
  ```
  Correct: `|retrieved[:k] ∩ gold| / |gold|`. Returns None for empty gold. ✅

- **MRR@k:** `src/evaluation/metrics.py:56–72`
  ```python
  def mrr(retrieved_doc_ids: list[str], gold_doc_ids: list[str], k: int):
      if not gold_doc_ids:
          return None
      gold_set = set(gold_doc_ids)
      for rank, doc_id in enumerate(retrieved_doc_ids[:k], start=1):
          if doc_id in gold_set:
              return 1.0 / rank
      return 0.0
  ```
  Correct: 1/rank of first relevant doc, 0 if none in top-k, None if no gold. ✅

- **nDCG@k:** `src/evaluation/metrics.py:76–108`
  - DCG: `sum(relevance[i] / log2(i+1) for i in range(k))`
  - IDCG: `sum(1 / log2(i+1) for i in range(min(len(gold), k)))`
  - nDCG: `DCG / IDCG` (returns None if empty gold)
  - Binary relevance (doc in gold → 1, else 0) ✅
