# E3 analysis specification — 12 November 2026

This is a post-hoc analysis of the existing, historically examined 300-question HotpotQA transfer study. It is not new held-out inference or a new confirmatory study. This specification is written before executing this analysis; earlier published aggregate results are already known.

Read only the frozen private protocol, candidate library, selected-poison seal and final evaluation tree. Require the published protocol/selection/completion/original-aggregate pins and exact file inventories. Validate native QA extraction, gold/target matching, source-target alignment and construction-failure accounting with the existing raw verifier. Never reconstruct query outcomes from aggregates. Export aggregate statistics and figures only.

The population is the same 300 questions in all 12 attack-family/intensity/seed strata; source pipelines BM25, Dense, Hybrid and Reranker; target pipelines those four plus frozen RCD. Failure observations contribute zero to full-population target matching and coverage, but have no invented clean/poisoned answer or exposure. Denominators are explicit. Distinguish candidate-band screening success from final source success; E3 uses the latter.

For each family/intensity/source/target, pool three seeds within questions. Report construction coverage, source-success rate among valid constructions, target matching per assignment and among valid constructions, and conditional transfer (source AND target success / source success). Zero denominators are undefined. Report target success conditional on final source success/failure and on generator-visible poison exposure, plus clean-gold-correct→poison-gold-wrong transitions, induced target matches (clean not target→poison target), clean target persistence, gold-accuracy/F1 changes, and counts of evidence-visible versus evidence-absent corruption. These are associations, not causal attribution of corruption to retrieval. Self-source/target controls are mechanically related, not independent transfer evidence.

For every bootstrap replicate, resample the 300 question IDs once and retain all seeds, source/target pipelines and outcomes of each sampled question together. Use 10,000 replicates, NumPy PCG64 seed 20261112, recompute ratios from summed numerators/denominators. Report undefined replicates. Descriptive estimates use percentile 95% intervals; they are not multiplicity-adjusted.

The planned directional family contains exactly four contrasts, one per attack family × intensity: ATR(BM25→Dense) minus ATR(Dense→BM25). Use the same question resample for both directions, and report percentile 98.75% intervals (Bonferroni four-comparison nominal familywise 95% coverage). Finite-bootstrap percentile intervals are approximate, not an exact finite-sample guarantee. No additional significance claims or adaptive contrast selection. All other source-target relationships, heatmaps, exposure associations and failure categories are descriptive/exploratory; do not infer significance from their unadjusted 95% intervals. No p-value fishing.

For Dense/Reranker/RCD failure-case analysis, publish grouped counts, including poison exposed but target not matched, target matched without visible poison, clean-correct→wrong with/without exposure, and pre-existing target matches. Do not export example text, question IDs or model outputs. This is a mechanistic taxonomy of saved observations, not independent semantic/factual adjudication. No parameter changes, retrieval replay or historical Qwen regeneration.
